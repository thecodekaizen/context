# SHOWME visual mockups

**Status:** two SHOWME concept mockups are available. They are exploratory, not validated product UI. Implementation and final visual polish remain behind the P0 capability gate.

- `00-thread-direction-board.png` — archived pre-pivot THREAD exploration from Oct 25, 2026. Its screens, copy, and visual language are not SHOWME requirements.
- `01-guided-task-states.png` — concept board showing normal camera guidance, a possible divergence, and recovery. The washer/motor-mount example is illustrative only; it is not the selected experiment task or evidence of detection capability.
- `02-what-if-procedure-preview.png` — concept screen for comparing a demonstrated order with a bounded alternative. It explicitly depicts procedural prediction, not physical simulation.

Planned SHOWME mockups, in priority order, are listed in [`../../docs/SHOWME_APP_PLAN.md`](../../docs/SHOWME_APP_PLAN.md). Use numbered, descriptive filenames. For each, document the represented state, evidence, interactions, and prototype limitations. Keep the actual physical task and evidence framing consistent across screens.
