# SHOWME visual mockups

**Status:** three SHOWME concept mockups are available. They are exploratory design references, not validated product UI or proof of capability. The separate [`../screenshots/`](../screenshots/README.md) folder contains captures from the running prototype.

- `00-thread-direction-board.png` — archived pre-pivot THREAD exploration from Oct 25, 2026. Its screens, copy, and visual language are not SHOWME requirements.
- `01-guided-task-states.png` — concept board showing normal camera guidance, a possible divergence, and recovery. The washer/motor-mount example is illustrative only; it is not the selected experiment task or evidence of detection capability.
- `02-what-if-procedure-preview.png` — concept screen for comparing a demonstrated order with a bounded alternative. It explicitly depicts procedural prediction, not physical simulation.
- `03-teach-skill-model-review.png` — generated concept for Teach: demonstration playback, candidate states, object observations, evidence timestamps, and human review of a proposed constraint. The colorful block assembly is illustrative and is not the selected evaluation task.

The mockups cover Do, Simulate, and Teach. Use numbered, descriptive filenames for any additions. For each, document the represented state, evidence, interactions, and prototype limitations. Keep the actual physical task and evidence framing consistent across screens.
