# Inspect screen specifications

The SVGs here are editable low-fidelity layout specifications created October 28, 2026. They are proposed final interactions, not screenshots or evidence of perception accuracy. Example parts and state labels are illustrative.

- [Teach](01-teach.svg): review demonstration, source facts and candidate before activation.
- [Do](02-do.svg): inspect workspace, current/historical checkpoint, difference and recovery evidence.
- [Simulate](03-simulate.svg): compare modeled arrangements, edit order, inspect supported consequence and return to task.

Use the [SHOWME design guide](../SHOWME_DESIGN_SYSTEM.md), [implementation backlog](../../docs/handoff/IMPLEMENTATION.md) and [product authority](../../docs/PRODUCT.md) together.

Earlier raster concepts are in [mockups](../mockups/README.md); their assembly is illustrative. Existing app captures are in [screenshots](../screenshots/README.md) and may predate current code. Do not claim the SVGs depict current implemented screens.

## Interaction acceptance

Teach: never overwrite an active model while a candidate is awaiting review. Do: later uncertainty cannot leave stale guidance presented as current. Simulate: label all modeled output and preserve the actual task state on return. All surfaces must support keyboard and narrow layouts.
