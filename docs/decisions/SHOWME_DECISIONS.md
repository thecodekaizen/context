# Record SHOWME decisions

Updated October 28, 2026. These decisions consolidate existing product agreements.

| ID | Decision | Reason and consequence |
| --- | --- | --- |
| D01 | SHOWME supersedes THREAD | Preserve reusable infrastructure; do not continue temporal-personal-discovery features. |
| D02 | Exactly Teach, Do, Simulate | One task journey; no conventional account/dashboard work. |
| D03 | One shared Skill Model | Prevent disconnected AI features and hidden simulation rules. |
| D04 | Learn one bounded physical procedure | General physical intelligence is outside hackathon scope. |
| D05 | Review extracted claims before activation | Structural validity cannot establish source truth. |
| D06 | Keep proposed and confirmed constraints separate | One observed order does not prove necessity. |
| D07 | Keep real and simulated state separate | UI playback cannot certify learner progress. |
| D08 | Use procedural simulation first | Visual state/relationship exploration before force/physics simulation. |
| D09 | Use explicit paid actions today | Current preview is local; snapshots/clips are discrete inference, not live monitoring. |
| D10 | Parallel frontend and perception work | Product development continues without manufacturing a capability pass. |
| D11 | Source access matters | Optional source PDF on Observe reduces reliance on extracted prose, but does not prove accuracy. |
| D12 | Preserve raw failures privately | Validation rejects remain inspectable; labels stay outside prompts and Git. |

## Open implementation questions

- Which observed states have enough visible evidence for task-specific geometric rendering?
- What minimum correction UI preserves a candidate's provenance and revision history?
- What observation cadence is useful given measured latency/cost? Do not promise continuous monitoring before measuring it.
- Which precise attached-state mistake is independently visible and repeatably recognized?

These are implementation/evidence questions, not permission to reopen the product. Add dated decisions with evidence and downstream effects when resolved.
