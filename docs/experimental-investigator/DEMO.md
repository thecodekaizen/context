# Three-minute demo plan

All dialogue below is intended framing, not an achieved result. Replace numerical statements with measured outcomes from frozen runs. If a capability fails, show or remove the claim rather than script success.

0:00–0:15 — Open on the task

Show two thermal components and a measured response. Explain: “These components heat each other. We want to predict their temperatures, and we have a limited experiment budget.” State whether the system is simulated or physical-data replay.

0:15–0:40 — Show ambiguity

Run the shared initial experiment. Overlay candidate predictions and observations. Show two explanations that fit the initial evidence similarly but disagree on a future input. Candidate explanations come from actual fits, not an authored reveal.

0:40–1:15 — Choose and run the distinguishing experiment

The investigator explains what it needs to distinguish, presents a bounded heater schedule, and stores predictions before execution. Run the simulator. Measurements rule out or weaken candidates. Show the corresponding revision and its evidence.

1:15–1:45 — Let the viewer challenge it

Choose a new heater schedule. Freeze the learned model's prediction; reveal the actual response and independent error. Give the declared tolerance and measured result. If investigations take longer than this segment, clearly label time compression and provide the full run.

1:45–2:10 — Show a surprise if validated

Change a simulated condition without revealing it to the investigator. Show the old model's failure, its diagnosis of uncertainty, and a further discriminating experiment. Use this segment only if change detection and recovery pass controlled tests. Otherwise use another unseen input and inspect unresolved ambiguity.

2:10–2:40 — Show the engineering and evidence

Open the ledger: Meta proposed/revised structure; numerical tools fitted models and selected/proposed experiments; measurements tested predictions. Show actual paired comparison results versus the strongest baseline, including failures, samples and budget. No fabricated saving percentage.

2:40–3:00 — State the bounded achievement

Explain the concrete result, what was built during the event and how to reproduce it. State remaining physical-validation limits. Position thermal identification as the first application, not evidence of arbitrary autonomous scientific discovery.

## Capture requirements

- Working local app and versioned run ID.
- Frozen scenario/protocol version, seed policy and comparison report.
- Actual model/version and token-cost record.
- Visible simulation/replay labels and measured/predicted legend.
- Full-run artifact accompanying any compressed highlight.
- Public repo with upstream attribution and instructions.
