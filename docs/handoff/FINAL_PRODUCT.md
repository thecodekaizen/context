# Deliver the SHOWME product

## Problem

A tutorial can show the expected procedure but cannot inspect the learner's workspace. SHOWME connects a learned physical procedure with evidence of another person's attempt.

## Product

A camera-first AI learns one bounded physical task from a demonstration, checks another person's work, identifies supported mistakes, guides recovery and explores alternative actions.

**The Skill Model is the product. Teach creates it. Do checks against it. Simulate explores it.** `../PRODUCT.md` is authoritative.

## Deliver three surfaces

### Teach

Record/upload an expert clip; optionally attach authoritative instructions and narration. Generate a candidate, inspect source evidence and uncertain claims, review relationships, activate the model. Do not silently approve it. Reference-derived steps must remain distinct from video-observed actions.

### Do

Open the workspace camera or a learner recording. Display current evidence, last matched checkpoint, next supported action, uncertainty and relevant parts. A supported difference opens its frame/evidence and recovery guidance. Verify recovery from later evidence rather than user clicks or simulated completion.

Current inference is explicit frame checks and recorded-video comparison. Continuous observation is a target, not a shipped fact. Camera preview alone does not analyze anything.

### Simulate

Start from the same reviewed model, optionally a clearly matched learner state. Propose an action/order, inspect the interpretation, run it, play/pause/step, compare with the reference and return to Do with real task context preserved. Show the resulting modeled arrangement, supporting relationship, uncertainty and recovery options.

A single observed order does not prove another order impossible. Proposed rules cannot block actions. Unsupported transitions stop as unknown. Geometry is presentation with disclosed provenance; no arbitrary-physics claim.

## Final demo

Expert demonstration → reviewed skill → learner progress → genuine mistake → grounded explanation → observed correction → visual what-if → return to task. Target one safe assembly, not arbitrary tasks. The recorded LEGO 30727 task is current experimental material; reliable full-set assistance is not established.

## Completion means

Product interactions work without hidden setup; the core mistake/recovery loop has repeatable evidence; public setup and a maximum three-minute demo accurately describe what was built. Deadline November 4, 2026, 9 PM ET. Verify final event requirements before submission.
