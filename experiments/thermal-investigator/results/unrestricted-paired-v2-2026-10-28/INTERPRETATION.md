# Contribution decision: current advantage claim fails this test

The preregistered 20% median-error improvement gate fails. Investigator median error is 0.006682°C, fixed numerical BIC 0.005194°C, numerical disagreement/BIC 0.006903°C, and direct Meta 0.006682°C. Investigator versus fixed wins 3 pairs and loses 7; versus direct it ties all 10. Paired intervals include zero against both numerical baselines; do not claim statistically established inferiority or superiority from this small sample.

All twenty Meta final executable models equal the unrestricted numerical model already fitted from the three common initial trials. The controllers therefore added no change to the scored predictive model in this batch. This reference is available without Meta, so fewer realized actions than a seven-trial baseline cannot establish experiment savings attributable to Meta.

Twelve of twenty Meta runs hit the eight-decision cap without an explicit stop. The raw results mark execution completed because no exception occurred; that is not autonomous successful termination. Eight explicitly stopped. No Meta case failed semantic validation in this corrected batch. The first version's twenty semantic failures are retained separately, and are not scientific evidence against the policies.

Two worlds share each of five underlying parameter seeds; ten cases are not ten independent parameter draws. The protocol's ordinary paired bootstrap is preserved. contribution-review.json adds an explicitly exploratory five-cluster bootstrap sensitivity check; it does not replace the preregistered result. Neither supports an advantage claim.

This is a feasibility comparison on known supplied families and one pre-existing sealed schedule. It does not prove that LLM investigation cannot help harder open-structure tasks. It does establish that our current claim is unsupported on this task, despite working live revision integration in the earlier deliberately restricted demonstration.

Decision: stop claiming better calibration or fewer experiments from the present investigator, and stop paying for prompt-only variants of this same benchmark. Keep the bounded executable models, transactional evidence store and API integration as useful infrastructure. A future contribution claim requires a genuinely different unresolved capability and a new preregistered test, not UI polish or selection of a favorable seed.

All eighty case records across both versions pass offline checks of executable predictions, hashes, scores, budgets and equal initial observations. These are internal consistency checks, not trusted provenance. No physical hardware or industrial savings were demonstrated.
