## Your assignment

Own the frontend experience and visual procedural simulation. Codex owns model integration, perception, recovery validation and backend experiments. Both use one Skill Model. Coordinate a shared contract change before implementing it.

Start by inspecting existing code and current Git changes. Preserve completed work. Implement one coherent user journey at a time; report changed files, checks, unsupported cases and next dependencies. Do not commit another agent's unreviewed work or reset the checkout.

The app exists. Improve it; do not generate a replacement application. Do not add authentication, dashboards, social features or marketplaces. Never present a fixture, animation or simulated result as successful physical perception.
