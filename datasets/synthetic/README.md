# Synthetic data

`creative-evolution.json` is the first rights-safe CLI fixture. It contains invented source text for the Meta extraction path and hand-authored theme annotations for the repeatable fixture path. The timeline includes a directional shift and later persistence of the earlier theme so the engine must report counter-evidence. Do not treat these examples as real personal history.

The seed set also includes a stable creative practice and unrelated topics incorrectly grouped into one archive. Run `python -m thread_engine.evaluate` from `backend/` to compare discovery with the labeled expected outcome for each. The disconnected-topics case guards against false evolution claims; see [`docs/EVALS.md`](../../docs/EVALS.md) for the lexical continuity tradeoff.
