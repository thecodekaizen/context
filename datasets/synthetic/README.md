# Synthetic data

`creative-evolution.json` is the first rights-safe CLI fixture. It contains invented source text for the Meta extraction path and hand-authored theme annotations for the repeatable fixture path. The timeline includes a directional shift and later persistence of the earlier theme so the engine must report counter-evidence. Do not treat these examples as real personal history.

The seed set also includes a stable creative practice, unrelated topics with distinct project IDs, and a genuine shift with little shared vocabulary. Run `python -m thread_engine.evaluate` from `backend/` to compare discovery with each labeled expected outcome. The loader rejects mixed project IDs, while same-project shifts do not depend on word overlap; see [`docs/EVALS.md`](../../docs/EVALS.md) for this boundary's assumptions.
