# Synthetic data

`creative-evolution.json` is the first rights-safe CLI fixture. It contains invented source text for the Meta extraction path and hand-authored theme annotations for the repeatable fixture path. The timeline includes a directional shift and later persistence of the earlier theme so the engine must report counter-evidence. Do not treat these examples as real personal history.

The seed set also includes a stable creative practice, unrelated topics with distinct project IDs, a genuine shift with little shared vocabulary, an impossible date, and duplicate source provenance. Run `python -m thread_engine.evaluate` from `backend/` to compare discovery with each labeled expected outcome. The loader rejects malformed dates, duplicate sources, and mixed project IDs; see [`docs/EVALS.md`](../../docs/EVALS.md) for this boundary's assumptions.
